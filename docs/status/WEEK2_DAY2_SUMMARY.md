## 💡 Lessons Learned

1. **Import Consistency:** Ensure all agents follow the same initialization pattern (config parameter)
2. **Abstract Methods:** BaseAgent subclasses must implement `shutdown()` method
3. **AgentCapability Enums:** Add capabilities as needed for new agent types
4. **Helper Functions:** Some agents need utility functions (e.g., `now_ts()`)
5. **Graceful Degradation:** System continues if agent initialization fails
6. **Detailed Logging:** Helpful during debugging, can be removed after validation
