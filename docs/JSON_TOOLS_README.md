# Kalki JSON Tools - Working with Design Data

The JSON files generated by Kalki contain valuable design information, specifications, and analysis results. Use these tools to view, analyze, and export your design data.

## What Each JSON File Contains

### 📄 `project.json`
- **Project metadata**: ID, name, description, status, timestamps
- **Blueprint summary**: Design intent, components, requirements
- **File inventory**: List of all generated deliverables

### 📋 `technical_specifications.json`
- **System overview**: Category, complexity, scale, component count
- **Physical specifications**: Weight, power, dimensions
- **Component details**: Individual part specifications and requirements

### 📊 `simulation_*.json` files
- **Structural analysis**: Stress, deformation, safety factors
- **Thermal analysis**: Heat distribution and thermal performance
- **Motion analysis**: Kinematics and dynamics simulation results

### 🖼️ `blueprint.json` & `blueprint_layout.json`
- **Detailed design data**: Component specifications, connections, parameters
- **Layout information**: Drawing dimensions, views, element positioning

## Using the JSON Tools

### View Project Summary
```bash
python json_tools.py view output/projects/PROJECT_ID/
```

### View Technical Specifications
```bash
python json_tools.py specs output/projects/PROJECT_ID/technical_specifications.json
```

### View Simulation Results
```bash
python json_tools.py sim output/projects/PROJECT_ID/simulation_structural_*.json
python json_tools.py sim output/projects/PROJECT_ID/simulation_thermal_*.json
python json_tools.py sim output/projects/PROJECT_ID/simulation_motion_*.json
```

### List All Projects
```bash
python json_tools.py list
```

### Export to CSV (requires pandas)
```bash
pip install pandas
python json_tools.py export input.json output.csv
```

## Practical Uses

### 📊 **Engineering Analysis**
- Review safety factors and stress analysis
- Check thermal performance metrics
- Validate motion simulation results

### 📋 **Manufacturing Preparation**
- Extract component specifications for procurement
- Get dimensional data for tooling
- Review material requirements

### 🖼️ **Design Documentation**
- Generate reports from technical specifications
- Export data for CAD software integration
- Create bill of materials

### 📈 **Design Iteration**
- Compare simulation results across design versions
- Track design parameter changes
- Analyze performance improvements

## Example Workflow

1. **Generate a design**:
   ```bash
   python design_cli.py "Design a robotic assembly system"
   ```

2. **Review the project**:
   ```bash
   python json_tools.py view output/projects/proj_20251103_xxxxxx/
   ```

3. **Check specifications**:
   ```bash
   python json_tools.py specs output/projects/proj_20251103_xxxxxx/technical_specifications.json
   ```

4. **Analyze simulations**:
   ```bash
   python json_tools.py sim output/projects/proj_20251103_xxxxxx/simulation_structural_*.json
   ```

5. **Export for external tools**:
   ```bash
   python json_tools.py export technical_specifications.json specs.csv
   ```

## Tips

- **PDF & SVG files** are your printable blueprints - open these directly
- **Simulation results** help validate design safety and performance
- **Technical specifications** contain all the detailed engineering data
- **Project.json** gives you the complete overview of what was generated

The JSON data is structured for both human reading and programmatic access, making it easy to integrate with other engineering tools and workflows.
