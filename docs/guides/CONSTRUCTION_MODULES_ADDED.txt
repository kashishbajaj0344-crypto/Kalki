🎯 WHAT THEY DO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROPERTY INTELLIGENCE GATHERER:
  Input: "1234 Elm Street, San Jose, CA 95125"
  
  Process:
    1. Searches Google for zoning info
    2. Researches setback requirements
    3. Finds permit requirements
    4. Identifies height limits
    5. Detects constraints (historic, flood, etc.)
  
  Output: Complete property intelligence report
    - Zoning: R-1, ADU allowed
    - Setbacks: 20' front, 5' side, 15' rear
    - Permits: Building, electrical, plumbing (~8 weeks)
    - Height: 30 ft max, 2 stories
    - Constraints: Historic overlay (moderate impact)
    - Complexity: 0.65/1.0
    - Opportunities: ["Large buildable area", "Flat lot"]

CONSTRUCTION JOURNEY MANAGER:
  Input: User answers to assessment questions
  
  Process:
    1. Uses LLM to analyze where user is in journey
    2. Identifies completed milestones
    3. Determines current stage (1-12)
    4. Detects blockers
    5. Recommends next actions
  
  Output: Current status & guidance
    - Current Stage: Design (stage 2/12)
    - Progress: 18%
    - Completed: ["Project vision defined", "Budget set"]
    - Next: ["Hire architect", "Schematic design"]
    - Blockers: None detected

ROADMAP GENERATOR:
  Input: Project type + property constraints
  
  Process:
    1. Selects base template (ADU/remodel/new construction)
    2. Applies property adjustments (complexity, constraints)
    3. Applies meta-learning adjustments (historical data)
    4. Generates 80-100 detailed steps
    5. Identifies critical path
    6. Calculates timeline & costs
  
  Output: Personalized roadmap
    - Total Steps: 82
    - Timeline: 51 weeks (adjusted for San Jose permits)
    - Cost: $178,500 (adjusted for expansive clay soil)
    - Critical Path: 28 steps
    - Immediate Next: ["Define vision", "Set budget", "Research zoning"]
