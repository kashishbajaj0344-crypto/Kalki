## Programmatic Usage

```python

# Standard synthesis

    "Design a sustainable water purification system",
    context={"scale": "village", "budget": "low_cost"},
    mode=SynthesisMode.ADVANCED
)

# Supreme synthesis
supreme_result = await synthesize_supreme(
    "Solve global climate change through technological innovation",
    context={"timeline": "century", "ethics": "maximize_harmony"},
    mode=SynthesisMode.SUPREME
)

# Access results
print(f"Quality Score: {result.quality_score}")

```
