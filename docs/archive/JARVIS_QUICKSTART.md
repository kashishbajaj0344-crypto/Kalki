## Step 2: Try It! (1 minute each)

### 💬 Chat
```bash
python3 kalki_cli.py chat
> Design me a robotic arm
```

### 📱 Generate iOS App
```bash
python3 kalki_cli.py dev app ios MyApp --monetization iap
```

### 🧠 Learn from PDF
```bash
python3 kalki_cli.py learn ingest handbook.pdf
```

### 🎮 Create Game
```bash
python3 kalki_cli.py dev game unity MyGame --genre action
```
