# Kalki Meta-Cognitive Control System

## Overview

The Meta-Cognitive Control System implements advanced AI reasoning capabilities including progressive depth management, interdisciplinary knowledge synthesis, and continuous self-improvement.

## Core Components

### 1. Progressive Reasoning Depth
- **Summary**: 1-pass heuristic reasoning for simple tasks
- **Standard**: 2-pass logical reasoning for moderate complexity
- **Deep Analysis**: 3-pass multi-domain simulation for complex problems
- **Auto**: Intelligent depth selection based on task assessment

### 2. Response Structuring
All analytical responses follow a standardized format:
1. **Executive Summary**: Concise overview
2. **Disciplines Considered**: Domains referenced
3. **Key Insights**: 3-5 primary takeaways
4. **Uncertainties & Confidence**: Quantified assessments
5. **Recommendations**: Actionable next steps

### 3. Quality Metrics & Self-Evaluation
- Interdisciplinary coverage scoring
- Coherence assessment
- User satisfaction estimation
- Efficiency ratio analysis
- Continuous improvement tracking

## Usage

### Command Interface

Use slash commands to control the meta-cognitive system:

```bash
# Set reasoning depth
/mode summary
/mode standard
/mode deep_analysis
/mode auto

# Set output style
/style conversational
/style structured
/style technical

# Check status
/status

# View quality trends
/trends

# Add knowledge
/learn quantum_mechanics superposition, entanglement, wave_function
```

### Programmatic Control

```python
from modules.meta_core import set_reasoning_depth, set_output_style, get_meta_status

# Set reasoning mode
set_reasoning_depth("deep_analysis")
set_output_style("structured")

# Check current status
status = get_meta_status()
print(status)
```
