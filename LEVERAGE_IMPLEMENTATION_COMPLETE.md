## 🚀 Usage Examples

### **Generate 3D Model:**
```python
result = await copilot.generate_3d_model(
    project_id="proj_123",
    specifications={"style": "modern", "materials": ["concrete", "glass"]}
)
```

### **Render Visualization:**
```python
render = await copilot.render_project_visualization(
    project_id="proj_123",
    render_type="photorealistic"
)
```

### **Validate Structure:**
```python
validation = await copilot.validate_structure(
    project_id="proj_123",
    load_cases=["static", "dynamic", "wind"]
)
```

### **Optimize Design:**
```python
optimized = await copilot.optimize_design_with_supreme_synthesis(
    project_id="proj_123",
    requirements={"budget": 500000, "sustainability": "high"}
)
```

### **Generate Blueprints:**
```python
blueprints = await copilot.generate_blueprints(
    project_id="proj_123",
    output_format="dwg"
)
```

### **Create Digital Twin:**
```python
twin = await copilot.create_digital_twin(
    project_id="proj_123",
    sensors=["temperature", "humidity", "vibration"]
)
```
