# 🎮 GameDev Copilot App - User Guide

## 🚀 Quick Start

### **Run the App:**

```bash
streamlit run apps/gamedev_copilot_app.py
```

The app will open in your browser at `http://localhost:8501`

---

## 📱 App Features

### **1. Create Game Tab** 💬

**Start a New Project:**
- Enter your game idea (e.g., "make me a carjam style game")
- Or click one of the example buttons
- Click "Start Project"

**Conversation Flow:**
- KALKI will research your game idea
- Answer questions about platforms, engine, monetization
- Use quick-select buttons or type your answers
- Watch as your game is created!

**After Project Creation:**
- View generated files
- Generate assets
- Deploy your game
- Polish and optimize

---

### **2. Projects Tab** 📁

**View All Projects:**
- See all your created games
- View project details (engine, platforms, files)
- Open project directories
- Deploy or polish existing projects

---

### **3. Help Tab** 📚

**Complete Guide:**
- How it works
- Tips and best practices
- Supported engines and platforms
- FAQ

---

## 🎯 Usage Example

1. **Open the app:** `streamlit run apps/gamedev_copilot_app.py`

2. **Start a project:**
   - Type: "make me a carjam style game"
   - Click "Start Project"

3. **Answer questions:**
   - "What platforms?" → Select "Both Android & iOS"
   - "What engine?" → Select "Unity"
   - "Monetization?" → Select "Freemium"

4. **Get your game:**
   - Code is generated automatically
   - View files in the Projects tab
   - Deploy or polish as needed

## 🎨 UI Features

- **Modern Design:** Clean, gradient headers, card-based layout
- **Color-Coded Status:** Visual indicators for project status

## 💡 Tips

- **Be specific** in your game description
- **Use examples** (carjam, flappy bird, etc.)
- **Answer all questions** for best results
- **Check the Projects tab** to see all your games
- **Use Polish** to improve your game after creation

---

## 🚀 What Happens Behind the Scenes

1. **Research:** KALKI researches your game idea
2. **Questions:** Smart questions gather requirements
3. **Code Generation:** Complete source code is generated
4. **Project Structure:** All files organized properly
5. **Ready to Build:** Your game is ready to deploy!

---

## 📁 Project Output

All games are saved to:
```
output/games/{project_id}/
```

Each project includes:
- Source code (Unity/Flutter/React Native/Web)
- Project configuration files
- Build scripts
- Deployment guides
- Setup instructions
